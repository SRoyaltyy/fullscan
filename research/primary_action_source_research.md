# Official-source research checkpoints

This is an engineering discovery record. Candidate endpoints become collection coverage only after a successful live parser check. Search results or a directory listing alone do not establish a working publication feed.

| Official hub | Purpose | Discovery/documentation |
|---|---|---|
| Federal Register | Agency identities and typed rules, proposed rules, notices, presidential documents | https://www.federalregister.gov/developers/documentation/api/v1 |
| GOV.UK organisations | Full paginated organisation registry, including closed/exempt bodies | https://www.gov.uk/api/organisations?page=1 |
| GOV.UK Search | Date-bounded typed decisions, tribunal outcomes, notices and related documents; one type per query | https://docs.publishing.service.gov.uk/repos/search-api/using-the-search-api.html |
| GovInfo | Participating court opinions and legislative/presidential publication feeds | https://www.govinfo.gov/feeds |
| USAGov | State/territory identities, not automatically verified state publication channels | https://www.usa.gov/state-governments |
| BIS | Central-bank identities; membership is not a feed-health assertion | https://www.bis.org/about/organisation/members |
| Congress | Official legislative source, not congress.com | https://www.congress.gov/rss/ |
| US Supreme Court | Official opinions and orders are separate publication channels | https://www.supremecourt.gov/orders/ordersofthecourt |
| OFAC | Recent sanctions actions, including dates in official publication URLs | https://ofac.treasury.gov/recent-actions |
| HKMA | Documented press-release JSON API, descending dates and offset pagination; unavailable endpoints remain disabled | https://apidocs.hkma.gov.hk/documentation/press-releases/ |
| HKMA API parameters | pagesize, offset, choose/from/to, sort order | https://apidocs.hkma.gov.hk/documentation/ |
| Hong Kong SFC | Official RSS discovery page; endpoints still require native parser verification | https://www.sfc.hk/en/RSS-Feeds |

The curated seed file contains discovery pages for US federal/state bodies, EU institutions, the UK, Canada, Australia, New Zealand, Hong Kong, Singapore, India, China, Japan, Korea, Taiwan, other Asian central banks, European national authorities, Latin American/African central banks and international institutions. The generated source catalog links every institution record and every checked publication channel, including unavailable and excluded endpoints. Source request audits retain URLs and response hashes rather than copyrighted search excerpts.
