# Sector Reflection — Consumer Cyclical — 2026-08-25

Triage: primary **reasoning failure**, not a tool/data failure. The Conference Board print was scheduled, consensus was below prior, and the relevant component was forward-looking — but the model neutralized it as “two-sided event risk” while giving full credit to the broad risk-on tape. The scoreboard `None/None` is a separate pipeline issue.

LESSON_BEGIN
ERROR_CATEGORY: A
TRIGGER_PATTERN: On a scheduled release day, a sector’s own high-impact hard-data print is pending; consensus is below the prior reading and the forward-looking component is a spending lead. The model names the print “the sector’s own print” but then treats it as neutral event risk in S1, while giving full positive credit to a broad risk-on tape in S0. When the print resolves below consensus, the discretionary ETF underperforms even on a rising SPY.
CURRENT_BEHAVIOR: Pending same-day sector-specific data is treated as unprinted/two-sided and therefore neutral in S1. Broad futures risk-on drives S0 = +1, and the output is up/flat with no downside tilt or confidence discount for the scheduled sector-own print.
CORRECTED_BEHAVIOR: When a same-day sector-owned print is scheduled with consensus below prior and the relevant component is forward-looking (e.g., Conference Board Expectations), do not neutralize it as pure event risk. Score a conditional downside tilt — either S1 slightly negative or S0 capped/discounted — rather than emitting a full positive call. Do not use “do not score a collapse that has not printed” to mean “no scheduled-downside risk”; distinguish not-yet-realized from not-risky.
EVIDENCE: 2026-08-25 Conference Board printed 89.4 vs ~90.3 consensus and 90.2 prior; the Expectations Index fell to 68.2, a seven-month low. XLY closed -0.30% while SPY rose +0.32%; XLY relative performance was -0.62%. Consumer staples/financials led while discretionary lagged, and AMZN/TSLA reversed lower. The print was knowable as scheduled, consensus was below prior, and the morning explicitly identified it as the sector’s own catalyst.
LESSON_MATCH_CHECK: Matches the 2026-08-25_sector_consumer_cyclical candidate lesson. It is distinct from the 08-21 lesson: 08-21 is about not keeping a stale down bias against a live risk-on tape; this lesson is about live scheduled downside risk in the sector’s own data.
BACKWARD_CHECK: Applying the rule to the visible recent consumer cyclical runs does not break 08-11, 08-17, 08-18, or 08-21 because those did not have a same-day sector-owned hard-data print with consensus below prior. It would have supported the 08-14 down call (July retail sales -0.6% m/m) and would have corrected 08-25 from up/flat to flat/down or down/mild. No obvious backward break.
CONFLICT_CHECK: No conflict with active lessons. 08-21 still governs stale-data cases; 08-18 still caps severe/notable downside; 08-17 still prevents stale hard-data from forcing notable. This lesson applies only to same-day scheduled sector-owned prints and does not force notable or severe magnitude.
APPLIED_LESSON_CHECK: The 08-21 risk-on lesson was applied correctly (kept direction up, shrunk confidence). The 08-17 stale-hard-data lesson was also applied correctly (did not force notable). However, no active lesson covered a pending same-day sector-owned print with consensus below prior, so this is a new lesson rather than a failure to apply an existing one.
FALSIFIER: If a same-day sector-owned print with consensus below prior resolves below consensus, but the sector ETF still closes up and outperforms SPY by more than ~0.5% on a risk-on tape with no offsetting sector-specific positive, then the “sector’s own print overrides broad tape” claim is falsified and this lesson should be demoted.
DIVERGENCE_VERDICT: none_flagged — no leading-vs-futures divergence was flagged; the realized XLY/SPY divergence came from an unmodeled scheduled-data risk, not from a divergence the components warned about.
ACTIVE_LESSON_REVIEW: 08-21, 08-11, 08-18, and 08-17 were applied appropriately. The `predicted None/None` scoreboard artifact is the separate pipeline/grader bug captured by other 08-25 sector candidates; it should be handled separately and not folded into this reasoning lesson.
