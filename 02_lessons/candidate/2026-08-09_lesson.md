The fix is forced-checklist enforcement at *file generation time*, not a new reasoning lesson, and the 08-08 candidate should be promoted rather than duplicated.

**CHECK 2 — BACKWARD TEST** — The proposed correction (fail loudly / block grading when the predict file is missing; never score a missing-baseline day as a miss) was scanned against recent history: it would have **helped** on **2026-08-08** (default `None/None` double miss from the same root cause, plus a stack of ungraded pending runs) and on **2026-08-02** (no scored baseline for the same reason). Resolution: consolidate all three observations into a single promoted D-category lesson implemented as a pipeline watchdog — not as prompt behavior.

**CHECK 5 — FALSIFIER** — If a pre-open watchdog is deployed and a scheduled trading day *still* reaches grading with no predict file and no loud alert, the implementation is broken — fix the tooling, do not defend the lesson.
