## RULE
S4 confirms only the session being predicted, not the prior close. If 8/25/8/27 forbids up (chemicals-heavy book, mixed/two-sided S1, no NQ>>ES materials impulse), the residual is flat (or flat/mild), not down. Do not double-count the same prior-session chemicals lag in S2 and S4. Require same-morning chemicals/premarket confirmation before S2 = −1. A live gold fade is an S1 sleeve, not a reason to keep stale chemicals scores. Two-sided Warsh/Chicago-style events stay two-sided in S0.

## WHEN IT FIRES
Basic Materials / XLB has S0 and S1 net-zero (no fresh China print, no metal surge/collapse, no Hormuz/oil>$90, two-sided scheduled event), and the only negatives are a prior-session chemicals-led breadth score (S2) plus the prior day's large negative 1d relative tape copied into S4. The model treats 8/25–8/27 "do not emit up" as a license to emit down.

## WRONG IF
Over the next 10+ XLB sessions with S0=S1=0, prior-day chemicals-led lag, prior 1d rel << −0.5%, and no fresh same-morning China/metal/macro HIT, if emitting flat instead of down misses because XLB still closes down >0.5% (or rel < −0.5%) with directional hit rate above ~60% on the stale-chemicals follow-through, the flat default is too strong and should be narrowed to magnitude-only.

## EVIDENCE
2026-08-28 predicted down/flat (S0 0 / S1 0 / S2 −1 / S3 0 / S4 −1, total −2.125). Actual XLB −0.094%, SPY −0.227%, rel +0.133%; open 53.66 vs prior 53.23 (gap-up then fade). Scoreboard: dir MISS, mag HIT. Primary driver was hawkish Warsh → gold ~−1.4% to −2% → NEM ~−3.3% / FCX ~−2.5%, offset by LIN +0.86%. Chicago PMI 47.1 was a real miss and did not set the close. Relative lag thesis failed.
