## RULE
When the narrative essay's final call diverges from the pipeline-computed decision, the model must explicitly reconcile: (a) state the pipeline output, (b) state the narrative output, (c) identify which components drive the disagreement, and (d) either adopt the pipeline call with justification or explain with specific evidence why the narrative overrides it. When the model's own governing lessons include "DO-INSTEAD: when score fights tape, cut conviction / prefer flat/mild," and the tape (1d rel +0.22%, 3d rel +1.01%) is positive while leading factors are negative, the correct application is flat/flat — not down/mild. The narrative must not present a final call that contradicts the deterministic pipeline without an explicit override rationale.

## WHEN IT FIRES
When the model's narrative essay and the pipeline-computed decision disagree on direction (narrative says down/mild, pipeline says flat/flat), and the model has an explicit DO-INSTEAD rule ("when score fights tape, cut conviction / prefer flat/mild"), the model must reconcile to a single final call rather than letting the narrative drift from the deterministic pipeline output. The divergence between narrative and pipeline is itself a signal that the leading-factor score is not robust enough to override the tape.

## WRONG IF
A future run where the narrative and pipeline disagree, the model explicitly reconciles them, adopts one call with clear justification, and the adopted call is correct (dir HIT). If the model reconciles but still misses, the lesson is not falsified — reconciliation is necessary but not sufficient for accuracy.
