## RULE
When a scheduled high-impact macro release is pending AND the pre-existing regime is already hawkish (rising real yields, negative 10Y-SPX corr), the model must pre-score asymmetric downside for long-duration growth sectors: S0 should be negative or zero (not +0.5) because the upside from a soft print is capped (relief only) while the downside from a hot print is amplified (compounds existing duration stress). Additionally, the model must reconcile its narrative direction with the pipeline-computed total_score before submission — if the narrative says "up/mild" but the components sum to a flat call, the model must either adjust the components to match the narrative or adjust the narrative to match the components. A flat prediction into a scheduled binary with a known hawkish skew is a miss regardless of which way the binary resolves.

## WHEN IT FIRES
When a scheduled high-impact macro release (NFP/CPI/FOMC) is pending and the model has already identified the pre-existing regime as hawkish (Fed/Warsh repricing, rising real yields, 10Y-SPX corr −0.943), the model treats the binary as symmetric and caps at flat/mild rather than pre-scoring the asymmetric downside for long-duration growth sectors. The model also fails to distinguish between the pipeline's deterministic flat output and its own narrative "up/mild" lean — the narrative and the scored output must be reconciled before submission.

## WRONG IF
A future session where a scheduled high-impact macro release is pending, the regime is hawkish, the model pre-scores asymmetric downside (S0 ≤ 0), and the print comes in soft — if the sector then rallies hard (≥ +1.5%) and the down/flat prediction misses, the asymmetric-downside rule would be falsified for that configuration. The rule should be refined to distinguish between "hot print compounds hawkish regime" (downside asymmetry) vs "soft print triggers relief rally" (upside potential) based on how much hawkishness is already priced.

## EVIDENCE
Predicted flat/flat (total_score −0.45) vs actual XLK +0.715% (dir MISS, mag MISS). The model's own narrative identified "NQ green +0.46%, positive follow-through" as supporting "up/mild" but the scored components produced flat. The 09-03 lesson (same pattern: two-sided catalyst refusal → flat → miss on ISM Services beat) was available but not applied. The 09-04 sector lessons for consumer cyclical, consumer defensive, financial, and healthcare all identified the same asymmetric-downside pattern for the NFP binary — this was a sector-wide known issue on this date.
