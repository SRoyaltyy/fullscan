Six effectiveness metrics

Start-date sustainability (would it still make money?)

If the recipe starts on day X and runs to the end, is the compounded return still positive? More YES days = less 8-13 pothole dependence.

How a recipe is graded

  1. Leak-free 09:30 inputs only. Cameras, 🔵/🚨, E/R/D, prior news, 20-bar OHLC, and 8-bar candles must be knowable before the open. Same-day Change% / Gap / RelVol / printed book never pick. News uses the morning box or the prior Finviz export — never a later scrape or post-09:30 headline.
  2. Time. Buy at the 09:30 open. Hold H sessions (entry day counts). Optional early exit at a later 09:30 if 🚨, last-bar red, or news🔴 prints that morning.
  3. Win rate. Share of picks with horizon return > 0 (long or short).
  4. $ days / average win %. Share of sessions whose equal-weight book made money, plus average win size vs average loss size.
  5. Sustainability. For every start date X, compound from X to the end. Count how often that path is still green.
  6. Top gainers / losers in the hold window. Buy 8-17 hold=3 → check 8-17, 8-18, 8-19 liquid top-25 gainers and names that printed < −1.5%.
