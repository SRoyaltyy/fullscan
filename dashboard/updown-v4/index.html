Is it better than guessing? (all tickers, walk-forward)

Brier score = average of (chance − outcome)², lower is better. A coin flip (always 50%) scores 0.2500. "Base rate" always guesses the share of ups seen in the training years. A horizon gets the green badge only if it beats both on non-overlapping days after a Holm multiple-testing penalty (adjusted p < 0.05).
Reliability: predicted chance (x) vs how often it actually went up (y), per horizon. On the diagonal = honest.

Which feature blocks help? (with vs without, walk-forward)

Each row = the v3 stock-level model plus one block. Δ = Brier with the block minus without (negative = helps). p values are Holm-adjusted across all 5 blocks × 4 horizons. "vs coin" is Holm-adjusted across all models × horizons.

Event study (every firing, 2020 → now, out-of-sample)

Excess = event stock's return minus the average stock the same day. Up edge = event up rate minus the same-day up rate. t on non-overlapping blocks; p Holm-adjusted across all events × horizons. "Real" = Holm p < 0.05 and same sign in 2020–22 and 2023–26.

Signal confluence (how many signal families fired in the last 5 sessions)

Families: volume surge (≥2× 20-day avg), Bollinger squeeze breakout, divergence, MACD/RSI cross, green/red extreme, VIX spike (market-wide; no free per-ticker option history). k = 2, 3, 4+ compared with k = 1 on the same days. "|move|" = size of the move regardless of direction. p Holm-adjusted across all k × horizon × measure.
