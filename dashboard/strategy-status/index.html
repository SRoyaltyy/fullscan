Any other status (missing / error / pick_fail / look_stale …) means the decision for that strategy is not final. Times are ET. "Finalized" is the ticket clock; "pushed" is the last commit of the dated ticket on main (GitHub API, best-effort). The dated file locks at 09:30 ET or the paper send; later publishes land in the draft and the evening copy is labelled as such. Input presence is a raw-file 200/404 probe of main — presence, not QC. fin / push under each strategy is the exact finalize and push time (ET, seconds): the ticket publishes all strategies atomically, so per-strategy finalize is the ticket seal clock and per-strategy push is the dated file's last commit on main — identical across rows by design; the quote snapshot time (px) is per-strategy inside the ⊕ panel. Click ⊕ to expand a strategy: its per-strategy record (px time, panel bake, signal date), the needs panel — every file the strategy reads, with its workflow role, a live OK/MISSING probe of main, the C.10 sha when the file is fingerprinted, and for factor recipes the parsed factor mix (universe, hold sessions, gates; combo members resolved to their sleeve recipes with weights, legend from src/factor_mine_combo.py) — and the exact hashed inputs: every sha256 in the C.10 decision fingerprint, identical ticket-wide, with absence hashed too. The "factor-mine dash updated" card is the last commit that touched dashboard/factor-mine/strategy_tickets.json: the publish pipeline lands dashboard copies in the same push as the tickets. Before the dated ticket for a session lands, every strategy shows NOT FINAL — a previous session's decisions are never substituted. The checks column is the one-row checklist of this strategy's own requirements — the item list differs per strategy: a news-gated factor recipe checks panel · freeze · state · news · judge, an AB-gated one checks ab instead, a stock_book strategy checks all 11 morning files. decision = the buy/sell is finalized (ok/sit in the landed ticket); every other item is one required input probed on main for the date — ✔ green = present, ✘ red = missing, … while probes run. Hover any mark for the full path; the ⊕ needs panel lists the same files with their workflow roles.
